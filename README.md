# SMAL(L)
Simple magic Arduino Language
———————
SMAL(L) was made, because, especially for beginners, c++ can be very hard. It uses a python script to translate the code into a list, which is sent to the arduino which executes the code.


SUPPORTED ARDUINOS
- Tested on Arduino uno r4
- should work on arduino mega and mega 2560
- should work on arduino uno
